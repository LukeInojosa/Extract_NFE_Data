# Extract_NFE_Data

Automação realizada em python para extrair informações de notas fiscais em xml e criar uma única planilha em csv com as informações de todas as notas ordenadas

# Como utilizar

1. Baixe suas notas fiscas em xml
2. Coloque as pastas com os arquivos .zip das notas fiscais na mesma pasta do main.py (não é necessário extrair as notas do zip)
3. Atualize no código o interst_fields
4. Rode o main.py 
5. será gerado um arquivo .csv com todas as informações das notas em interest_fields
